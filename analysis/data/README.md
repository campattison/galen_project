# Frozen inputs

These files are inputs to the analyses, not outputs. They record exactly what was used; do not
regenerate and overwrite them with other software versions. The scripts in `../optional/` rerun the
software that made the Stanza output, the Diorisis form index, the COMET-Kiwi scores and the token
counts and compare with these files, without overwriting them.

## The rarity measure

| File | What it is | Provenance |
|---|---|---|
| `stanza_lemmas.csv` | One row per word Stanza produced for the 20 passages of `corpus_metrics/comp.txt` and `mix.txt`: `text, chunk, word_index, word, upos, lemma, diorisis_freq, counted_in_metric` (`counted_in_metric` = UPOS is not PUNCT, as in the original measure) | Stanza 1.11.0, default Ancient Greek (`grc`) pipeline with `tokenize,pos,lemma`, run by J. Zainaldin, 18 Sept 2026. This run reproduces every value of `corpus_metrics/passage_difficulty_zipf.csv` (checked by `07_rarity_measure.py`). Its Comp. 1 is the preface of book I, which `comp.txt` holds in place of the passage translated and evaluated; the corrected measure uses this file for the other 19 passages. |
| `stanza_lemmas_comp1_translated.csv` | The same for Comp. 1 as translated and evaluated (I.2, XIII.367,10–369,1 K.; 251 rows, 224 counted) | Stanza 1.11.0 with the same `grc` models, run on the Greek of passage 1 of `mt_eval/input/on_comp.txt` as the pipeline's parser reads it, 24 Sept 2026 |
| `stanza_version.txt` | The version string written by that run | as above |
| `diorisis_form_index.json` | For every word form in the two Stanza files: how often Diorisis files it under each lemma, keyed by canonical Beta Code (`form`) and by bare letters (`bare`) | Built from the 820 Diorisis XML files (Vatri & McGillivray 2018, CC BY 4.0) by `../optional/build_diorisis_form_index.py`, which also checks the lemma counts against `corpus_metrics/diorisis_frequencies.json` |
| `lemma_decisions.csv` | The words whose Stanza lemma and Diorisis lemma (for the same form) disagree about rare vs common, with the decision for each (`final_lemma`). Rows 1–23 cover the words of `stanza_lemmas.csv` (`occurrences` and `passages` count them there; ἀποθήκῃ and ῥοὰς occur only in its Comp. 1, the preface, and are not used); rows 24–26 cover the words of the translated Comp. 1 | Decided by J. Zainaldin, September 2026. `recorded_choice` is the choice as recorded; `resolution_note` gives the reason where a word was not simply assigned the Stanza or the Diorisis lemma (ἐτῶν = "years"; δεῖ and δεῖν counted under δέω) and for rows 24–26 |
| `lemma_check_sample.csv` | A random sample of 50 repaired lemmas (25 Mix., 25 Comp.) and the hand check of each: is the corrected lemma right (`lemma_correct`), and is the word correctly classed as rare or common (`status_correct`) | Drawn with NumPy `default_rng(2026)`, 25 per text, from the 449 repaired tokens of `stanza_lemmas.csv` (3 of the 25 Comp. words come from its Comp. 1, the preface); checked by J. Zainaldin, 18 Sept 2026. `answer_recorded` is the answer as recorded; `resolution_note` explains the answers that needed interpretation. `09_lemma_check.py` redraws the sample from the seed. |

## Automated metric scores

| File | What it is | Provenance |
|---|---|---|
| `mt_eval_scores.csv`, `mt_eval_scores_per_reference.csv` | The automated metric scores of all 60 translations (the pipeline's multi-reference scores, and for Mix. the score against each reference), with Mix. 2 and 4 rescored after the fix described in `mixtures_pre_fix/README.md` (`changed_by_reference_fix`) | Exported by C. Pattison, 21 Sept 2026, from the evaluation files regenerated by the pipeline (`mt_eval/`) after the fix. `common.load_eval` applies them to the evaluation files in `mt_eval/output/evaluations/` and checks that only Mix. 2 and 4 change. |
| `mt_eval_aggregates.csv` | Means and SDs of the same scores by text and model | Exported with them; `01_reference_asymmetry.py` checks the scores against it |
| `mixtures_pre_fix/` | The Mix. input file and its evaluation file before the fix | see `mixtures_pre_fix/README.md` |
| `comet_kiwi_scores.csv`, `comet_kiwi_run_info.txt` | The COMET-Kiwi (`Unbabel/wmt22-cometkiwi-da`) score of each of the 60 translations against its Greek source, with the token counts of the model's input window, and the settings of the run | Run by C. Pattison, 21 Sept 2026 (unbabel-comet 2.2.7, CPU, batch size 8, NFC-normalised inputs). `../optional/comet_kiwi.py` scores the translations with the same settings and compares its results with this file. `33_table_input_limits.py` checks the file's token counts against `token_counts_*.csv` and its COMET and TQS columns against this package's. |
| `token_counts_passages.csv`, `token_counts_pairs.csv`, `token_counts_README.md` | Every text (20 Greek sources, 60 translations, 30 references) counted with each metric's own tokenizer, and for each scored pair what COMET, COMET-Kiwi, BERTScore and BLEURT keep of it | Made by C. Pattison, 24 Sept 2026 (`../optional/token_counts.py`); `token_counts_README.md` gives the tokenizers, their versions and the library code behind each rule. `33_table_input_limits.py` re-applies every truncation rule to the raw counts and checks the word counts against the texts in this repository before using them. |
